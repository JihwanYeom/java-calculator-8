# java-calculator-precourse

---

## 🛠️구현할 기능 목록

- [ ] 문자열 입력
- [ ] 숫자 추출 및 검증
- [ ] 커스텀 구분자 추출 및 검증
- [ ] 숫자 및 구분자를 이용한 덧셈
- [ ] 결과 출력

## ⚠️예외 처리
- [ ] 피연산자로 음수가 입력된 경우
- [ ] 피연산자로 숫자 외의 값이 입력된 경우
- [ ] 문자열에 기본, 커스텀 구분자, 숫자 외의 문자가 입력된 경우
- [ ] 구분자와 구분자 사이가 공백일 경우
- [ ] 커스텀 구분자 지정 형식이 잘못되었을 경우
- [ ] 커스텀 구분자로 숫자가 입력된 경우

## 🤔고민되는 점
